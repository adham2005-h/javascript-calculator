# حاسبة بسيطة

## التقنيات

HTML وCSS وJavaScript.

## فكرة المشروع

الجمع والطرح والضرب والقسمة، مع المسح وحذف آخر رقم وإدخال الكسور.

## التشغيل

1. نزّل المستودع أو انسخه.
2. افتح `index.html` في متصفح حديث.
3. احتفظ بمجلدات الصور والملفات في مواقعها الحالية حتى تعمل المسارات.

## ملفات البداية

- `index.html`
- `main.js`
- `styles.css`

## حدود المشروع

تُنفّذ العمليات المتتابعة بالترتيب، مثل الحاسبة البسيطة؛ لا تستخدم أولوية العمليات. اختبر: 2 + 3 + 4 = 9، و5 / 0 يعرض Error، وكتابة رقم بعد = تبدأ حسابًا جديدًا.
